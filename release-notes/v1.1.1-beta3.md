# v1.1.1-beta3: presets for VW in the green menu
Test release. Install it like v1.1.0: copy everything in the zip to the card. Your edited `ClusterMap/gal_dualscreen.conf` can be kept.

**New**
- **Green menu headings.** The `ClusterMap` screen now groups its entries: map settings, presets, and porting (the collect entries).
- **Presets:** VW original (DPI 125, insets `40,40,127,127`), VW Golf (DPI 125, `53,47,127,127`), VW custom (DPI 140, `105,127,127,127`) and SEAT (DPI 140, `105,127,127,127`). Each press saves; reboot to apply.

Not yet tested on a car.
