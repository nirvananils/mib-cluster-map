# v1.1.1-beta2: map settings in the green menu
Test release. Install it like v1.1.0: copy everything in the zip to the card. Your edited `ClusterMap/gal_dualscreen.conf` can be kept.

**New**
- **DPI and insets from the green menu.** The `ClusterMap` screen has a **Map settings** part: DPI +5/-5, each inset (top, bottom, left, right) +5/-5, and two presets: the shipped values (DPI 125, insets `40,40,127,127`) and the SEAT values (DPI 140, insets `105,127,127,127`). Each press saves to the unit's copy of the settings and to the card's `ClusterMap/gal_dualscreen.conf`, and moves the CarPlay safe area with the insets. Reboot to apply. **Show current DPI and insets** reads them from the settings file the hook uses, names other copies that differ, and shows from the hook log which file was loaded at boot and what DPI and insets went to the phone.
- **Releases are built on GitHub** by a workflow from the tagged commit.

Not yet tested on a car.
